Executive Summary

This project explores changes in U.S. county-level voting behavior between the 2020 and 2024 Presidential elections. Election results were scraped from Wikipedia due to inconsistencies in official state election websites and official county boundary shapefiles were obtained from the U.S. Census Bureau. Key findings from the analysis include both absolute and proportional changes in voting patterns, turnout and geographic characteristics.

Highlights of Key Findings

  • Largest Number of Trump Votes (2024): Los Angeles County, California cast the highest number of votes for Donald Trump in 2024, over 1.18 million votes. However, this may be due to the county’s large population, not a Republican majority.
  • Highest Proportion of Biden Votes (2020): Kalawao County, Hawaii recorded 95.8% of its votes for Joe Biden, the highest percentage in the nation, though from a very small voter base.
  • Largest Absolute Gain for Trump (2024): Los Angeles County, California also saw the largest increase in Trump votes from 2020 to 2024, an increase of 44,332 votes.
  • Biggest Shift Toward Harris (2024): Florida experienced the largest shift in vote margin in favor of Kamala Harris with a gain of approximately 371,686 votes.
  • Largest County by Land Area: Yukon-Koyukuk County, Alaska is the largest in the dataset, covering over 377 billion square meters, aligning with known geographic facts.
  • Highest Voter Density (2020): New York County, New York had the highest voter density, with 0.01 voters per square meter, reflecting high population density in a small area.
  • Highest Increase in Voter Turnout (2020–2024): Montgomery County, Texas saw the biggest rise in total votes cast, increasing by 35,715 votes from 2020 to 2024.

Introduction

After the 2024 U.S. Presidential election, The New York Times published a map suggesting that many counties across the United States had shifted toward the Republican party compared to 2020. This visual quickly spread online and shaped public discussions around a possible nationwide political “vibe shift.” This project aims to investigate the changes in vote shares between the 2020 and 2024 presidential elections at the county level as well as recreate and evaluate the original map.

Data on election results at the county-level was collected for both years from Wikipedia pages for each state. While not a primary source, Wikipedia provided a reliable and practical alternative due to the challenges of collecting data from official state websites, which are often inconsistent and difficult to automate. For mapping, the U.S. county boundary shapefiles from the U.S. Census Bureau’s Cartographic Boundary Files (2023) was used and the finest available resolution (1:500,000) was selected to ensure high-quality geographic visualizations. By combining cleaned election results with accurate county shapes, the shift in Republican vote share in each county was calculated and visualized using tools in R. This project offers a data-driven look at whether the supposed nationwide political shift is supported by the numbers and where that shift, if any, was most pronounced.

safe_filename <- function(state) {

# Scraping function for a single state
scrape_state_results <- function(state) {
  message("Processing: ", state)
  
  # Construct Wikipedia path and local cache path
  base_url <- "https://en.wikipedia.org/wiki"
  path <- paste0("2024_United_States_presidential_election_in_", gsub(" ", "_", state))
  html_path <- file.path("data/mp04/wikipedia_pages", paste0(safe_filename(state), ".html"))
  
  # Download HTML only if not already saved
  if (!file.exists(html_path)) {
    req <- request(base_url) |>
      req_url_path_append(path) |>
      req_perform()
    writeBin(resp_body_raw(req), html_path)
  }
  
  # Read the HTML and extract all tables
  html <- read_html(html_path)
  tables <- html_elements(html, "table") |> html_table(fill = TRUE)
  
  # Find table with a column like "County", "Parish", "Borough", etc.
  target_table <- NULL
  for (tbl in tables) {
    colnames_lower <- tolower(names(tbl))
    if (any(str_detect(colnames_lower, "county|parish|borough|city and borough"))) {
      target_table <- tbl
      break
    }
  }
  
  # If not found, return NULL with warning
  if (is.null(target_table)) {
    warning("No county-level table found for ", state)
    return(NULL)
  }
  
  # Clean and return table with state column
  cleaned <- target_table |>
    clean_names() |>
    mutate(state = state)
  
  return(cleaned)
}

    mutate(total_2020 = parse_number(total_2020))
}

if (!is.numeric(shapes_combined$total_2024)) {
  shapes_combined <- shapes_combined |>
    mutate(total_2024 = parse_number(total_2024))
}

# Calculate change in turnout
shapes_combined <- shapes_combined |>
  mutate(turnout_change = total_2024 - total_2020)

# Identify county with largest increase
largest_turnout_increase <- shapes_combined |>
  filter(!is.na(turnout_change)) |>
  arrange(desc(turnout_change)) |>
  slice_max(turnout_change, n = 1) |>
  select(state, county, total_2020, total_2024, turnout_change)

# Display result in formatted table
largest_turnout_increase |>
  st_drop_geometry() |>
  mutate(
    state = str_to_title(state),
    county = str_to_title(county),
    total_2020 = comma(total_2020),
    total_2024 = comma(total_2024),
    turnout_change = comma(turnout_change)
  ) |>
  kable(
    caption = "County with the Largest Increase in Voter Turnout  2024",
    col.names = c("State", "County", "Votes in 2020", "Votes in 2024", "Increase in Turnout"),
    align = "lclrr",
    format = "html"
  ) |>
  kable_styling(
    bootstrap_options = c("striped", "hover", "condensed"),
    full_width = FALSE,
    position = "center"
  )
